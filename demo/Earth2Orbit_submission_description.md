# Earth2Orbit — submission texts

## Video description (English)
**Earth2Orbit** (team ITSTEP Lviv Earth2Orbit) is an independent NASA Space Apps Challenge 2026 project for the challenge
**“Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars.”**
Moon and Mars missions need places on Earth where equipment and methods can be rehearsed. Earth2Orbit is an interactive
3D explorer and catalog: pick a Moon or Mars location, open documented Earth analogs, see them on a map, read live
NASA POWER climate data, and compare documented features side by side — including where each analogy breaks down.
The demo shows Jezero Crater (Mars) → Atacama Desert → comparison with Devon Island. It is a learning and early-research
tool, not proof that any site is suitable for landing or a base.

**NASA data and its role**
- NASA POWER (power.larc.nasa.gov) — live regional climate normals (temperature, precipitation, solar energy) for each Earth site.
- NASA / JPL and NASA Earth Observatory pages — sources for the documented analog features in the catalog.
- NASA LROC imagery (Moon texture), NASA/JPL images in galleries — credited in the app.
- In the project (not shown in this video): LRO LOLA and MGS MOLA elevation data from the NASA Planetary Data System.

**Other sources and libraries:** OpenStreetMap (map tiles, via Leaflet), Solar System Scope textures (CC BY 4.0),
FURY Data Earth imagery, React, Three.js, Leaflet, Node.js. ESA sources are cited in the catalog.
